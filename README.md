# Meus sites favoritos

Projeto da atividade de Desenvolvimento Web I.

## Como executar
1. Extraia a pasta do arquivo ZIP.
2. Abra `index.html` no navegador.
3. Para personalizar, substitua `Seu Nome` pelo seu nome completo no título principal.

## Sobre as imagens
As imagens dos cinco sites são carregadas por endereços externos de ícones (favicon). Portanto, é necessário estar conectado à internet para visualizá-las.

## Publicar no GitHub
1. Crie um repositório público no GitHub chamado `meus-sites-favoritos`.
2. Envie o arquivo `index.html` e este `README.md` para o repositório.
3. Para publicar como site, abra **Settings > Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`, depois salve.
